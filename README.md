# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリとは、インターネット上、または社内ネットワーク上のサーバーにあるリポジトリのことで、チームの全員がアクセスできる「中央の共有スペース」として、プロジェクトの最新状態や全員の変更履歴を保管する。

- ローカルリポジトリとは、自分のパソコン内にあるリポジトリのことで、自分専用の作業スペースとして、ファイルの追加や変更、過去の履歴の記録（コミット）を行う。

## プッシュとマージの違いは何でしょうか？
- プッシュは「自分の作業をサーバーに送信して共有する操作」であり、マージは「別のブランチの作業履歴を大元のブランチに取り込む操作」のこと。  
役割が全く異なるため、目的に応じて使い分ける。


## コミットとプッシュの違い
- コミットとプッシュの違いは、作業履歴の保存場所で、コミットは自分のパソコン内にファイル変更の履歴を記録する操作であり、プッシュはローカルリポジトリに記録した履歴を、インターネット上のサーバーへアップロードして共有する操作である。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 誰が読んでも変更内容とその変更理由が一目でわかるように書くことが最適。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでのマージは自身のPC内で完結する作業であるのに対し、プルリクエストでのマージはチームメンバーによるコードレビューのプロセスを経てリモート上で統合される仕組み。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
1. 先にマージされた変更内容を取り込む
1. 後にマージしようとしている変更内容を取り込む
1. どちらの変更内容も取り込む

コンフリクトの内容によって、1～3のうち当てはまる方法を、コンフリクトしているコードを書いた対象者と相談しながら実施する。
